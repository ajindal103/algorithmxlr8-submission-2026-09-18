# Longest Repeating Character Replacement

**Difficulty:** `Medium`

## Problem

Given a string s of uppercase English letters and an integer k, you may replace at most k characters of s with any other uppercase letter. Return the length of the longest substring containing a single repeated letter that can be achieved this way.

Read s on the first line of standard input and k on the second line. Print the length of the longest achievable substring to standard output.

## Examples

### Example 1

**Input**
```
ABAB
2
```
**Output**
```
4
```

**Explanation:** Replacing both B's (or both A's) makes the entire string one repeated letter.

### Example 2

**Input**
```
AABABBA
1
```
**Output**
```
4
```

**Explanation:** A single replacement can make a length-4 substring uniform, but no longer substring can be made uniform with just 1 replacement.
