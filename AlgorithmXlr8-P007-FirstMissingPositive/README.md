# First Missing Positive

**Difficulty:** `Hard`

## Problem

Given an unsorted integer array nums, return the smallest missing positive integer.

Your algorithm must run in O(n) time and use only O(1) extra space, beyond the input array itself.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the smallest missing positive integer to standard output.

## Examples

### Example 1

**Input**
```
3
1 2 0
```
**Output**
```
3
```

**Explanation:** 1 and 2 are present, so the smallest missing positive is 3.

### Example 2

**Input**
```
4
3 4 -1 1
```
**Output**
```
2
```

**Explanation:** 1 is present but 2 is missing, so the answer is 2.

### Example 3

**Input**
```
5
7 8 9 11 12
```
**Output**
```
1
```

**Explanation:** 1 itself is missing entirely, so the answer is 1.
