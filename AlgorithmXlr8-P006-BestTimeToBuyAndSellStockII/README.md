# Best Time to Buy and Sell Stock II

**Difficulty:** `Medium`

## Problem

Given prices (unlimited buy/sell transactions, must sell before buying again), maximize total profit.

Read n on the first line, then n space-separated prices. Print the maximum total profit.

## Examples

### Example 1

**Input**
```
prices = [7,1,5,3,6,4]
```
**Output**
```
7
```

**Explanation:** Capture the 1->5 and 3->6 increases for total profit 7.
