# Group Anagrams

**Difficulty:** `Medium`

## Problem

Given an array of strings strs, group the anagrams together (words that use exactly the same letters, rearranged).

Read n on the first line of standard input, then n space-separated strings on the second line. Print each group on its own line, its words space-separated, in the order each group was first encountered while scanning strs, and with words within a group kept in their original input order.

## Examples

### Example 1

**Input**
```
6
eat tea tan ate nat bat
```
**Output**
```
eat tea ate
tan nat
bat
```

**Explanation:** eat, tea, and ate share the same letters; tan and nat share the same letters; bat stands alone.

### Example 2

**Input**
```
1
a
```
**Output**
```
a
```

**Explanation:** A single word is trivially its own group.
