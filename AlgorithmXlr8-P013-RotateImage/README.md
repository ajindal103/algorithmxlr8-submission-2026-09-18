# Rotate Image

**Difficulty:** `Medium`

## Problem

Given an n x n 2D matrix representing an image, rotate the image by 90 degrees clockwise, in place.

Read n on the first line, followed by n lines each with n space-separated integers, on standard input. Print the rotated matrix: n lines, each with n space-separated integers.

## Examples

### Example 1

**Input**
```
3
1 2 3
4 5 6
7 8 9
```
**Output**
```
7 4 1
8 5 2
9 6 3
```

**Explanation:** Transposing then reversing each row rotates the matrix 90 degrees clockwise.

### Example 2

**Input**
```
4
5 1 9 11
2 4 8 10
13 3 6 7
15 14 12 16
```
**Output**
```
15 13 2 5
14 3 4 1
12 6 8 9
16 7 10 11
```

**Explanation:** The same transpose-then-reverse technique applies to a 4x4 matrix.
