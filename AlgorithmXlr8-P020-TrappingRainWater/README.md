# Trapping Rain Water

**Difficulty:** `Hard`

## Problem

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the total trapped water to standard output.

## Examples

### Example 1

**Input**
```
12
0 1 0 2 1 0 1 3 2 1 2 1
```
**Output**
```
6
```

**Explanation:** Water pools in the dips between taller bars, totaling 6 units.

### Example 2

**Input**
```
6
4 2 0 3 2 5
```
**Output**
```
9
```

**Explanation:** Even a deep dip near the start still traps water, since a tall enough bar exists on each side, totaling 9 units.
