# Maximum Average Subarray I

**Difficulty:** `Easy`

## Problem

Given an integer array nums and an integer k, find a contiguous subarray of length exactly k that has the maximum average value, and return that average.

Read n and k on the first line of standard input, then n space-separated integers on the second line. Print the maximum average, formatted to exactly 5 decimal places, to standard output.

## Examples

### Example 1

**Input**
```
1 12 -5 -6 50 3
```
**Output**
```
12.75000
```

**Explanation:** The window [12,-5,-6,50] has the largest sum, 51, giving an average of 12.75.

### Example 2

**Input**
```
5
```
**Output**
```
5.00000
```

**Explanation:** With only one element and a window size of 1, the average is the element itself.
