# Rotate Array

**Difficulty:** `Medium`

## Problem

Given an integer array nums, rotate the array to the right by k steps, where k is non-negative.

Read n and k on the first line of standard input, then n space-separated integers on the second line. Print the rotated array, space-separated, to standard output.

## Examples

### Example 1

**Input**
```
7 3
1 2 3 4 5 6 7
```
**Output**
```
5 6 7 1 2 3 4
```

**Explanation:** The last 3 elements move to the front, and the rest shift right.

### Example 2

**Input**
```
4 2
-1 -100 3 99
```
**Output**
```
3 99 -1 -100
```

**Explanation:** The last 2 elements move to the front.
