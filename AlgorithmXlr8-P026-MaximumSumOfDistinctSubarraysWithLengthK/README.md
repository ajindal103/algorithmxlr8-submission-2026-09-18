# Maximum Sum of Distinct Subarrays With Length K

**Difficulty:** `Medium`

## Problem

Given an integer array nums and an integer k, find the maximum subarray sum among all contiguous subarrays of length k with no duplicate elements. If no such subarray exists, return 0.

Read n and k on the first line of standard input, then n space-separated integers on the second line. Print the maximum qualifying sum to standard output.

## Examples

### Example 1

**Input**
```
7 3
1 5 4 2 9 9 9
```
**Output**
```
15
```

**Explanation:** The window [4,2,9] sums to 15 and has no duplicates, the best valid window.

### Example 2

**Input**
```
3 3
4 4 4
```
**Output**
```
0
```

**Explanation:** The only window, [4,4,4], has a repeated value, so no valid window exists.
