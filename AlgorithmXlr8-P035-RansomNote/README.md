# Ransom Note

**Difficulty:** `Easy`

## Problem

Given two strings ransomNote and magazine, return true if ransomNote can be constructed using the letters available in magazine, where each letter of magazine can be used at most once.

Read ransomNote on the first line and magazine on the second line of standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
a
b
```
**Output**
```
false
```

**Explanation:** magazine has no 'a' at all.

### Example 2

**Input**
```
aa
ab
```
**Output**
```
false
```

**Explanation:** ransomNote needs two a's, but magazine only has one.

### Example 3

**Input**
```
aa
aab
```
**Output**
```
true
```

**Explanation:** magazine has two a's, enough to cover ransomNote's needs.
