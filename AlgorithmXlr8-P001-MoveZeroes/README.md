# Move Zeroes

**Difficulty:** `Easy`

## Problem

Given an integer array nums, move all 0's to the end of it while maintaining the relative order of the non-zero elements.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the resulting array, space-separated, to standard output.

## Examples

### Example 1

**Input**
```
5
0 1 0 3 12
```
**Output**
```
1 3 12 0 0
```

**Explanation:** The non-zero values 1, 3, 12 keep their relative order, and both zeroes move to the end.

### Example 2

**Input**
```
1
0
```
**Output**
```
0
```

**Explanation:** A single zero stays a single zero.

### Example 3

**Input**
```
3
1 2 3
```
**Output**
```
1 2 3
```

**Explanation:** With no zeroes at all, the array is unchanged.
