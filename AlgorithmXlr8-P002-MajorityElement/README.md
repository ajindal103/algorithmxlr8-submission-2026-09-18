# Majority Element

**Difficulty:** `Easy`

## Problem

Given an array nums of size n, return the majority element, the element that appears more than n / 2 times.

You may assume the majority element always exists in the array.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the majority element to standard output.

## Examples

### Example 1

**Input**
```
3
3 2 3
```
**Output**
```
3
```

**Explanation:** 3 appears twice out of three elements, more than half.

### Example 2

**Input**
```
7
2 2 1 1 1 2 2
```
**Output**
```
2
```

**Explanation:** 2 appears four times out of seven, more than half.
