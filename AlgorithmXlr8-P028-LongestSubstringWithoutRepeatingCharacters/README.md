# Longest Substring Without Repeating Characters

**Difficulty:** `Medium`

## Problem

Given a string s, return the length of the longest substring without repeating characters.

Read s as the single line of standard input. Print the length of the longest repeat-free substring to standard output.

## Examples

### Example 1

**Input**
```
abcabcbb
```
**Output**
```
3
```

**Explanation:** The substring "abc" has length 3, the longest repeat-free stretch.

### Example 2

**Input**
```
bbbbb
```
**Output**
```
1
```

**Explanation:** Every character is the same, so the answer is 1.

### Example 3

**Input**
```
pwwkew
```
**Output**
```
3
```

**Explanation:** The substring "wke" has length 3; "pwke" is not a valid substring since it isn't contiguous.
