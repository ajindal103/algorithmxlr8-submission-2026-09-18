# Continuous Subarray Sum

**Difficulty:** `Medium`

## Problem

Given an integer array nums and an integer k, return true if nums has a contiguous subarray of size at least 2 whose sum is a multiple of k (0 counts as a multiple of any k), and false otherwise.

Read n and k on the first line, then n space-separated integers on the second line. Print true or false.

## Examples

### Example 1

**Input**
```
nums = [23,2,4,6,7], k = 6
```
**Output**
```
true
```

**Explanation:** The subarray [2,4] sums to 6, a multiple of 6.

### Example 2

**Input**
```
nums = [23,2,6,4,7], k = 6
```
**Output**
```
true
```

**Explanation:** The whole array sums to 42, a multiple of 6.
