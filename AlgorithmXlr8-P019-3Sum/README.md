# 3Sum

**Difficulty:** `Medium`

## Problem

Given an integer array nums, find all unique triplets [nums[i], nums[j], nums[k]], with i, j, and k all different indices, whose values sum to 0. The result must not contain duplicate triplets.

Read n on the first line of standard input, then n space-separated integers on the second line. Print each triplet on its own line, with the three values space-separated in ascending order, and the triplets themselves in ascending order. If no such triplet exists (for example, [0, 1, 1] has none), print nothing.

## Examples

### Example 1

**Input**
```
6
-1 0 1 2 -1 -4
```
**Output**
```
-1 -1 2
-1 0 1
```

**Explanation:** The two unique zero-summing triplets are (-1, -1, 2) and (-1, 0, 1).

### Example 2

**Input**
```
3
0 0 0
```
**Output**
```
0 0 0
```

**Explanation:** The only possible triplet is (0, 0, 0), which sums to 0.
