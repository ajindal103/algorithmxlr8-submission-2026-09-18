# Container With Most Water

**Difficulty:** `Medium`

## Problem

Given n non-negative integers height, where each represents a vertical line at position i with that height, find two lines that, together with the x-axis, form a container that holds the most water.

Read n on the first line of standard input, then n space-separated integers on the second line. Print the maximum area of water the container can hold to standard output.

## Examples

### Example 1

**Input**
```
9
1 8 6 2 5 4 8 3 7
```
**Output**
```
49
```

**Explanation:** The lines at indices 1 and 8 (heights 8 and 7) span a width of 7, giving an area of min(8,7) * 7 = 49.

### Example 2

**Input**
```
2
1 1
```
**Output**
```
1
```

**Explanation:** With only two lines, the container's area is min(1,1) * 1 = 1.
