# Set Matrix Zeroes

**Difficulty:** `Medium`

## Problem

Given an m x n integer matrix, if an element is 0, set its entire row and entire column to 0, doing this in place.

Read rows and cols on the first line, followed by rows lines each with cols space-separated integers, on standard input. Print the resulting matrix: rows lines, each with cols space-separated integers.

## Examples

### Example 1

**Input**
```
3 3
1 1 1
1 0 1
1 1 1
```
**Output**
```
1 0 1
0 0 0
1 0 1
```

**Explanation:** The zero at (1,1) causes row 1 and column 1 to be fully zeroed.

### Example 2

**Input**
```
3 4
0 1 2 0
3 4 5 2
1 3 1 5
```
**Output**
```
0 0 0 0
0 4 5 0
0 3 1 0
```

**Explanation:** The zeros at (0,0) and (0,3) cause row 0 and columns 0, 3 to be fully zeroed.
