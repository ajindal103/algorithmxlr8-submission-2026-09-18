# Permutation in String

**Difficulty:** `Medium`

## Problem

Given two strings s1 and s2, return true if s2 contains a permutation of s1 as a substring (some contiguous substring of s2 uses exactly the same letters, in any order, as s1).

Read s1 on the first line and s2 on the second line of standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
ab
eidbaooo
```
**Output**
```
true
```

**Explanation:** The substring ba is a permutation of ab.

### Example 2

**Input**
```
ab
eidboaoo
```
**Output**
```
false
```

**Explanation:** No substring of s2 uses exactly one a and one b together.
