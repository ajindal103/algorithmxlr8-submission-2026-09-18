# Reverse a String

**Difficulty:** `Easy`

## Problem

Given a string s, return s with its characters reversed.

Read the entire line s from standard input, and print the reversed string to standard output.

## Examples

### Example 1

**Input**
```
hello
```
**Output**
```
olleh
```

**Explanation:** Reading hello backward gives olleh.

### Example 2

**Input**
```
Hannah
```
**Output**
```
hannaH
```

**Explanation:** Hannah happens to be a palindrome, so it reverses to itself with the case preserved character by character.

### Example 3

**Input**
```
a
```
**Output**
```
a
```

**Explanation:** A single character reversed is itself.
