# Minimum Window Substring

**Difficulty:** `Hard`

## Problem

Given two strings s and t, return the smallest substring of s that contains every character of t, including duplicates (that is, if t has two a's, the window must contain at least two a's).

If no such window exists, return an empty string.

Read s on the first line and t on the second line of standard input, and print the minimum window substring (or an empty line if none exists) to standard output.

## Examples

### Example 1

**Input**
```
ADOBECODEBANC
ABC
```
**Output**
```
BANC
```

**Explanation:** BANC is the smallest substring of s containing all of A, B, and C.

### Example 2

**Input**
```
a
a
```
**Output**
```
a
```

**Explanation:** The entire string a already contains everything t needs.
