# Find All Anagrams in a String

**Difficulty:** `Medium`

## Problem

Given two strings s and p, return all the start indices of p's anagrams in s.

Read s on the first line and p on the second line of standard input, and print every valid start index, space-separated in ascending order, to standard output.

## Examples

### Example 1

**Input**
```
cbaebabacd
abc
```
**Output**
```
0 6
```

**Explanation:** The substring starting at index 0 (cba) and the one starting at index 6 (bac) are both anagrams of abc.

### Example 2

**Input**
```
abab
ab
```
**Output**
```
0 1 2
```

**Explanation:** Every 2-character window in abab (ab, ba, ab) is an anagram of ab.
